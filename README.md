# THE AGE SCHOOL - Local Fee Management System

## Features
- Login screen
- Student search
- Add/Edit/Delete student structure
- Fee payment entry
- PDF receipt placeholder
- Class-wise reports placeholder
- Outstanding fee report
- Docker support

## Run without Docker

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm start

## Run with Docker
docker compose up -d

Frontend: http://localhost:3000
Backend: http://localhost:5000
